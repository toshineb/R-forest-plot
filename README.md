# SILC vs MILC — Umbrella Review Forest Plots

## Overview

Systematic umbrella review forest plots comparing Single-Incision Laparoscopic Cholecystectomy (SILC) vs Multi-Port Laparoscopic Cholecystectomy (MILC).

## Project Structure

- **notebooks/** — Jupyter notebook with Python implementation
- **scripts/** — R scripts for forest plot generation
- **figures/** — Generated forest plot figures (TIFF, 300 DPI, 18 cm wide)
- **docs/** — Documentation and conversion guides

## Technologies Used

- **Python**: matplotlib, pandas, numpy (Jupyter implementation)
- **R**: ggplot2, tidyverse, gridExtra (production R implementation)

## Key Outputs

18 forest plot figures organized into:

- **Figure 2**: Patient-Reported Outcomes (4 panels)
- **Figure 3**: Surgical Efficacy Outcomes (5 panels)
- **Figure 4**: Surgical Safety Outcomes (6 panels)

## Getting Started

### Python (Jupyter)

```bash
jupyter notebook notebooks/SILC_vs_MILC_Forest_Plots.ipynb
```
